# Statistics glossary

Every term used in the course, A to Z. The number in brackets is the lesson where it's introduced.

| Term | Meaning |
|---|---|
| **1.96** | The z-value with 2.5% of the standard normal beyond it; ±1.96 holds the middle 95%. [9] |
| **68-95-99.7 rule** | The share of normal values within 1, 2 and 3 standard deviations of the mean. [9] |
| **Absolute lift** | The difference between rates, in percentage points. [22] |
| **A/B test** | A randomised experiment comparing a control (A) with a new version (B). [22] |
| **Adjusted R²** | R² penalised for the number of predictors. [21] |
| **Alternative hypothesis (H₁)** | The claim that there is an effect or difference. [14] |
| **ANOVA (analysis of variance)** | A test of whether three or more group means are all equal. [18] |
| **Bayes' rule** | P(A \| B) = P(B \| A) × P(A) / P(B), used to reverse a conditional probability. [7] |
| **BCa interval** | A more accurate bootstrap interval that corrects for bias and skew; SciPy's default. [13] |
| **β (beta)** | The probability of a Type II error. [16] |
| **Between-group variation** | How far the group means are from the overall mean. [18] |
| **Bias** | A systematic error that pushes results in one direction. [10] |
| **Bimodal** | Having two peaks, often two groups mixed together. [4] |
| **Bin** | One range of values in a histogram. [4] |
| **Binary variable** | A variable with two values, often coded 1 (yes) and 0 (no). [5] |
| **Binomial distribution** | The number of successes in n independent tries with success probability p. [8] |
| **Bonferroni correction** | Dividing α by the number of tests. [16] |
| **Bootstrap** | Estimating uncertainty by recomputing a statistic on many resamples of your data. [13] |
| **Bootstrap distribution** | The statistic's values across all resamples. [13] |
| **Box plot** | A chart of the quartiles, whiskers and outliers. [3] |
| **Categorical variable** | A variable whose values are labels, like city or product. [1] |
| **Causation** | One variable directly changing another. [19] |
| **Caveat** | A stated limit on how far results can be trusted or generalised. [23] |
| **cdf (cumulative distribution function)** | P(X ≤ k). [8] |
| **Central limit theorem (CLT)** | For large enough samples, sample averages are approximately normal, centred on the population mean, with standard deviation σ / √n. [11] |
| **Chi-square (χ²) test** | A test comparing observed counts with the counts expected under H₀. [17] |
| **Cluster sample** | Randomly chosen whole groups, with everyone in them measured. [10] |
| **Coefficient** | The estimated effect of one predictor, holding the others fixed. [21] |
| **Coefficient of variation (CV)** | The standard deviation divided by the mean. [3] |
| **Cohen's d** | A difference between means measured in standard deviations. [15] |
| **Combination / permutation** | The number of ways to choose items without order / to arrange them in order. [6] |
| **Complement** | "not A"; P(not A) = 1 − P(A). [6] |
| **Conditional probability** | The probability of A given that B happened, written P(A \| B). [7] |
| **Confidence interval** | A range of plausible values for a population number, built so that a stated share of such ranges contain it. [12] |
| **Confidence level** | The long-run share of intervals that contain the true value, usually 95%. [12] |
| **Confounder** | A third variable that influences both variables in a relationship. [19] |
| **Continuous** | Able to take any value in a range. [9] |
| **Control / treatment** | The current version, and the version being tested. [22] |
| **Convenience sample** | Whoever is easiest to reach; usually biased. [10] |
| **Correlation** | A measure of how two variables move together. [19] |
| **Correlation matrix** | A table of the correlations between every pair of variables. [19] |
| **Cramér's V** | The strength of association between two categorical variables, from 0 to 1. [17] |
| **Critical value** | How many standard errors to go out on each side (about 1.96 for 95% with the normal distribution). [12] |
| **Degrees of freedom** | A number that sets the t distribution's shape; n − 1 for one mean. [12] |
| **Degrees of freedom (chi-square)** | (rows − 1) × (columns − 1) for a two-way table. [17] |
| **Descriptive statistics** | Summarising the data you have. [1] |
| **Deviation** | A value's distance from the mean. [3] |
| **Discrete** | Taking separate, countable values like 0, 1, 2. [8] |
| **Distribution** | How the values of a variable are spread across possible values. [4] |
| **Dummy variable** | A 0/1 column representing one category. [21] |
| **Effect size** | How big a difference or relationship is, separate from whether it's significant. [14] |
| **Eta squared (η²)** | The share of total variation explained by the groups. [18] |
| **Event** | A set of outcomes, like "an even number". [6] |
| **Expected count** | How many would fall there if H₀ were true. [17] |
| **Expected value** | The long-run average of a random variable: each value times its probability, summed. [8] |
| **Exploratory analysis** | Describing and visualising data before testing anything. [23] |
| **Extrapolation** | Predicting outside the range of the data. [20] |
| **False negative** | Saying "no" when the truth is "yes". [7] |
| **False positive** | A test or model saying "yes" when the truth is "no". [7] |
| **Fisher's exact test** | An exact test for 2 × 2 tables with small counts. [17] |
| **Fitted value** | The model's prediction for a row in the data. [23] |
| **Formula** | Text like `"price ~ area + C(neighborhood)"` describing a model. [21] |
| **Frequency** | How many times a value occurs. [5] |
| **F statistic** | The ratio of between-group to within-group variation. [18] |
| **Goodness-of-fit test** | Tests whether counts match a claimed distribution. [17] |
| **Guardrail metric** | A measure that mustn't get worse, like revenue or page speed. [22] |
| **Heatmap** | A grid of coloured cells, often used to show a correlation matrix. [19] |
| **Histogram** | Bars counting how many values fall into each range (bin). [4] |
| **Hypothesis test** | A method for judging whether data gives evidence against a "no effect" explanation. [14] |
| **Independent events** | Events where one happening doesn't change the chance of the other. [6] |
| **Inferential statistics** | Drawing conclusions about the population from a sample, with a measure of uncertainty. [1] |
| **Intercept** | The predicted y when x is 0. [20] |
| **IQR (interquartile range)** | Q3 minus Q1, the spread of the middle 50%. [3] |
| **Joint probability** | The probability that A and B both happen. [7] |
| **Kruskal-Wallis test** | A rank-based alternative to one-way ANOVA. [18] |
| **Law of large numbers** | With more repetitions, the observed share gets closer to the true probability. [6] |
| **Least squares** | Choosing the line that minimises the sum of squared residuals. [20] |
| **Left-skewed** | A long tail of small values; the mean is below the median. [4] |
| **Like-for-like comparison** | Comparing groups with other factors held fixed. [23] |
| **Linear regression** | Fitting a straight line to predict an outcome from a predictor. [20] |
| **Log transform** | Analysing log(x) instead of x to pull in a long right tail. [4] |
| **Mann-Whitney U test** | A rank-based alternative to the two-sample t-test. [15] |
| **Margin of error** | The "±" part of a confidence interval. [12] |
| **Mean** | The sum of the values divided by how many there are; the "average". [2] |
| **Median** | The middle value when the values are sorted. [2] |
| **Minimum detectable effect** | The smallest effect a study is designed to detect. [16] |
| **Minimum detectable effect (MDE)** | The smallest lift the test is sized to detect. [22] |
| **Mode** | The most common value. [2] |
| **Multicollinearity** | Strong correlation between predictors. [21] |
| **Multiple regression** | Regression with several predictors. [21] |
| **Multiple testing** | Running many tests, which makes some false alarms likely. [16] |
| **√n** | The square root of the sample size; why precision grows slowly with more data. [11] |
| **Non-response bias** | Bias because people who respond differ from those who don't. [10] |
| **Normal distribution** | The symmetric bell-shaped distribution set by its mean μ and standard deviation σ. [9] |
| **Normality test** | A test (like Shapiro-Wilk) of whether data could come from a normal distribution. [9] |
| **Null distribution** | The values the test statistic would take if H₀ were true. [14] |
| **Null hypothesis (H₀)** | The default claim of no effect or no difference. [14] |
| **Numerical variable** | A variable whose values are numbers you can do maths with. [1] |
| **Observational data** | Data collected without randomly assigning anything, which shows associations rather than proven causes. [23] |
| **Observed count** | How many cases actually fell in a category. [17] |
| **OLS (ordinary least squares)** | The standard way of fitting a linear regression. [21] |
| **One-sample t-test** | Compares one group's mean with a fixed value. [15] |
| **Ordinal variable** | Categories with a natural order, like small, medium, large. [1] |
| **Outcome** | One possible result of a random process, like rolling a 4. [6] |
| **Outcome (dependent variable)** | The variable being predicted, y. [20] |
| **Outlier** | A value far from the others. [2] |
| **Paired t-test** | Compares two measurements on the same subjects, using each subject's difference. [15] |
| **Parameter** | A true number for the whole population, like the average height of every adult. [1] |
| **pdf (probability density function)** | The height of the curve; probabilities are areas under it. [9] |
| **Pearson's r** | The strength and direction of a straight-line relationship, from −1 to +1. [19] |
| **Peeking** | Checking results repeatedly and stopping when they look significant. [22] |
| **Percentile interval** | The middle 95% of the bootstrap distribution (2.5th to 97.5th percentiles). [13] |
| **Permutation test** | A test that builds the null distribution by shuffling group labels. [14] |
| **p-hacking** | Trying analyses until something comes out significant. [16] |
| **pmf (probability mass function)** | P(X = k) for a discrete variable. [8] |
| **Point estimate** | A single best guess, like the sample mean. [12] |
| **Poisson distribution** | The number of events in a fixed interval when they happen at a steady average rate λ. [8] |
| **Population** | Everything or everyone you want to draw conclusions about. [1] |
| **Posterior** | The updated probability after seeing the evidence. [7] |
| **Post-hoc test** | A follow-up test that finds which groups differ. [18] |
| **Power** | The probability of detecting a real effect, 1 − β; 80% is a common target. [16] |
| **ppf (percent point function)** | The value with a given area to its left; the inverse of the cdf. [9] |
| **Precision** | Of everything flagged as positive, the share that really is. [7] |
| **Predictor (independent variable)** | The variable used to predict, x. [20] |
| **Primary metric** | The one measure the test is designed to judge. [22] |
| **Prior (base rate)** | The probability before seeing new evidence, like how common a disease is. [7] |
| **Probability** | A number from 0 (impossible) to 1 (certain) for how likely something is. [6] |
| **Proportion** | A count divided by the total, between 0 and 1. [5] |
| **p-value** | The probability of a result at least as extreme as the one observed, if H₀ were true. [14] |
| **Quartiles** | The values that split sorted data into four equal parts: Q1, the median and Q3. [3] |
| **Randomisation** | Assigning users to groups by chance, so the groups differ only in the change. [22] |
| **Random variable** | A number produced by a random process. [8] |
| **Range** | The largest value minus the smallest. [3] |
| **Rate** | A proportion of a group, like the conversion rate. [5] |
| **R² (coefficient of determination)** | The share of the variation in y explained by the model. [20] |
| **Reference category** | The category the dummy variables are compared with. [21] |
| **Regression to the mean** | Extreme results tend to be followed by less extreme ones. [20] |
| **Relative frequency** | Another name for proportion. [5] |
| **Relative lift** | The difference divided by the control rate, as a percentage. [22] |
| **Resample** | A sample drawn from your own data, with replacement, the same size as the original. [13] |
| **Residual** | Actual y minus predicted y. [20] |
| **Right-skewed** | A long tail of large values; the mean is above the median. [4] |
| **Robust** | Not much affected by outliers. The median is robust; the mean is not. [2] |
| **Row percentages** | Each row of a two-way table divided by its row total. [5] |
| **Sample** | The part of the population you actually measure. [1] |
| **Sample ratio mismatch (SRM)** | Groups that differ in size more than chance allows, usually a sign of a bug. [22] |
| **Sampling distribution** | The distribution of a statistic (like the mean) over many samples. [11] |
| **Sampling variability** | The natural difference between one random sample and another. [10] |
| **Scatter plot** | A chart with one dot per row, placed by two numerical variables. [19] |
| **Selection bias** | Bias from who ends up in the sample. [10] |
| **sf (survival function)** | P(X > k) = 1 − cdf. [8] |
| **σ (sigma)** | The population standard deviation. [11] |
| **Significance level (α)** | The cut-off for calling a result significant, usually 0.05. [14] |
| **Simple random sample** | A sample where every member of the population has the same chance of being chosen. [10] |
| **Simulation** | Estimating a probability by imitating the random process many times. [6] |
| **Skewed** | Having a long tail on one side. [2] |
| **Slope** | The average change in y for a one-unit increase in x. [20] |
| **Spearman's ρ (rho)** | A correlation computed on ranks, measuring any steadily rising or falling relationship. [19] |
| **Spread (variability)** | How far values are spread out. [3] |
| **Standard deviation (std)** | The square root of the variance: the typical distance from the mean. [3] |
| **Standard error of a proportion** | √(p(1 − p) / n). [11] |
| **Standard error (SE)** | The standard deviation of a statistic across samples; for a mean, s / √n. [10] |
| **Standardising** | Converting values to z-scores so different variables share one scale. [4] |
| **Standard normal** | The normal distribution with mean 0 and std 1. [9] |
| **Statistic** | A number calculated from a sample, used to estimate a parameter. [1] |
| **Statistically significant** | P below α; evidence against H₀, not necessarily an important effect. [14] |
| **Statistics** | Learning about a whole group from data about part of it, and saying how sure you are. [1] |
| **statsmodels** | A Python library for statistical models and tests. [21] |
| **Stratified sample** | Random samples taken separately from each group (stratum), so every group is represented. [10] |
| **Survivorship bias** | Bias from looking only at the cases that "survived" some filter. [10] |
| **t distribution** | A bell-shaped distribution with fatter tails than the normal, used when the std is estimated from the sample. [12] |
| **Test of independence** | Tests whether two categorical variables are related. [17] |
| **Test statistic** | A number that measures how far the data is from what H₀ predicts. [14] |
| **t statistic** | A difference divided by its standard error. [15] |
| **t-test** | A test comparing means using the t distribution. [15] |
| **Tukey's HSD** | A post-hoc test comparing every pair while controlling false alarms. [18] |
| **Two-proportion z-test** | A test comparing two rates, like conversion rates. [22] |
| **Two-sided test** | A test that counts extreme results in both directions. [14] |
| **Two-way (contingency) table** | Counts for every combination of two categorical variables. [5] |
| **Type I error** | A false alarm: rejecting H₀ when it's true. [16] |
| **Type II error** | A miss: failing to reject H₀ when there is a real effect. [16] |
| **Variable** | Something recorded about each row, such as a score or a city. [1] |
| **Variance** | The average squared deviation (dividing by n − 1 for a sample). [3] |
| **VIF (variance inflation factor)** | A measure of how much multicollinearity inflates a coefficient's uncertainty. [21] |
| **Weighted mean** | An average where some values count more than others. [2] |
| **Welch's t-test** | Compares two independent groups without assuming equal spreads. [15] |
| **Wilcoxon signed-rank test** | A rank-based alternative to the paired t-test. [15] |
| **Within-group variation** | How spread out values are inside each group. [18] |
| **With replacement** | Each draw can pick a row that was already picked. [13] |
| **z-score** | (value − mean) / std: how many standard deviations a value is from the mean. [4] |
